# Coffee Shop Sales Analysis | SQL Project

## Project Overview
This project focuses on analyzing coffee shop sales data using MySQL.
The objective is to identify business trends, understand customer
purchasing behavior, and evaluate product and city-wise sales performance.

## Objectives
- Analyze total coffee sales revenue.
- Identify top-selling coffee products.
- Compare sales performance across cities.
- Analyze customer purchasing frequency.
- Calculate monthly sales growth.
- Evaluate product revenue contribution.

## Tools & Technologies
- MySQL
- SQL
- MySQL Workbench

## SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- INNER JOIN
- Aggregate Functions
- Common Table Expressions (CTEs)
- CASE Statements
- Window Functions
- Date Functions
- Revenue and Growth Analysis

## Business Questions
1. What is the total coffee revenue in Q4 2023?
2. How many units of each coffee product were sold?
3. What is the average sales amount per customer in each city?
4. What are the city populations and estimated coffee consumers?
5. What are the top 3 selling products in each city?
6. How many unique coffee customers are there in each city?
7. How do average sales compare with estimated rent?
8. What is the monthly sales growth in each city?
9. How can customers be segmented by purchasing frequency?
10. Which products contribute the most revenue in each city?

## Key Learnings
- Improved SQL querying and data analysis skills.
- Practiced joining multiple relational tables.
- Used CTEs and window functions for advanced analysis.
- Developed business insights from sales data.
